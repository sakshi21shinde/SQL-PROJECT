
# 🍔 Swiggy Food Delivery Analysis – SQL Project

## 📌 Project Overview
This project focuses on analyzing Swiggy food delivery data using MySQL. The objective is to understand food delivery operations, customer behavior, restaurant performance, and order trends through SQL queries.

The project uses a relational database containing multiple interconnected tables to perform meaningful data analysis and generate business insights.

## 🎯 Project Objectives
- Analyze customer ordering patterns.
- Identify top-performing restaurants.
- Understand food delivery trends.
- Analyze order status and delivery performance.
- Calculate revenue and order statistics.
- Retrieve meaningful insights using SQL queries.

## 🛠️ Technologies Used
- **Database:** MySQL
- **Language:** SQL
- **Platform:** MySQL Workbench

## 🗂️ Database Tables
The project includes 5 relational tables:

1. **Customers** – Stores customer information.
2. **Restaurants** – Stores restaurant details.
3. **Orders** – Contains order-related information.
4. **Delivery** – Stores delivery details.
5. **Feedback** – Contains customer ratings and reviews.

## 📚 SQL Concepts Covered

| SQL Concept | Application |
|---|---|
| DDL | CREATE, ALTER, DROP |
| DML | INSERT, UPDATE, DELETE |
| DQL | SELECT |
| Constraints | PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL |
| Filtering | WHERE, LIKE, BETWEEN, IN |
| Aggregate Functions | SUM, AVG, COUNT, MIN, MAX |
| Grouping | GROUP BY, HAVING |
| Sorting | ORDER BY |
| Joins | INNER JOIN, LEFT JOIN, RIGHT JOIN |
| Subqueries | Nested queries |
| Views | CREATE VIEW |
| Window Functions | RANK, DENSE_RANK, ROW_NUMBER |

## 📊 Business Analysis
The project answers business-related questions such as:

- Which restaurants receive the highest number of orders?
- Who are the customers placing the most orders?
- What is the total revenue generated?
- Which orders are successfully delivered?
- What is the average customer rating?
- Which restaurants have the highest average ratings?
- Which customers have never placed an order?
- What are the top-performing restaurants based on revenue?

## 💡 Key Learnings
- Understanding relational database structures.
- Creating and managing tables using SQL.
- Establishing relationships using primary and foreign keys.
- Writing SQL queries to extract meaningful information.
- Applying joins, subqueries, views, and window functions.
- Solving real-world business problems using SQL.
